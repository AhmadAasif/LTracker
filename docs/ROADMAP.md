# ELORA roadmap
1. Encrypted local backup and restore.
2. Profile, goals and editable preferences.
3. Local notifications with Android permission and reboot handling.
4. Progress charts and date filters.
5. User-adjustable workouts and meal planning.
6. Benchmark an optional small quantized on-device model on the target OPPO A5 5G before integration. Core features must never depend on it.
7. Run analyze, tests, Android debug/release builds and manual Android 16 / ColorOS validation.

Privacy rules: keep records on-device; never transmit data without explicit opt-in; require approval before changing budgets or routines; avoid extreme diets and medical claims.
